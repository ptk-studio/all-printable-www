# all-printable — declared metrics

**What this product is trying to move.** Public on purpose: a metric nobody can see is a metric
nobody can be held to.

> **Not yet declared, and deliberately not inherited.** Until 2026-09-04 this repo was worked
> as part of a project whose declared metric was **DAU on the app**
> ([`all-printable-app-www`](https://github.com/ptk-studio/all-printable-app-www)). That metric
> measures the catalogue, not the marketing home, and copying it here would have made this file
> wrong on its first line.
>
> Declaring one is the first thing an agent on this project owes. A one-page site whose job is
> to send people to the app suggests something about referral or click-through rather than
> visits, but **that is a guess and must not be written here as a target** until someone has
> established what can actually be read.

**Never write a value nobody read.** If a reading cannot be taken, say it was skipped rather
than writing a plausible number. A definition never changes in the same commit as a value.
